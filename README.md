# Pomodoro Timer

A web-based Pomodoro timer designed to help users manage their time and stay focused through structured work and break intervals.

This project was developed as a team project for the **Digital Literacy and Artificial Intelligence** module in the first year at **ESI Algiers** (École nationale Supérieure d'Informatique).

## Features

- Three timer modes: Focus, Short Break, and Long Break
- Visual progress ring with a live countdown
- Daily session goal and total focused time
- Session history saved locally in the browser
- Customizable durations, daily goal, and auto-start option
- Light and dark themes
- Sound notification when a session ends
- Motivational quotes

## Technologies

HTML, CSS, and vanilla JavaScript. No frameworks or dependencies. Data is stored with the browser's localStorage.

## Run locally

    git clone https://github.com/WalidKsentini/Pomodoro-Timer.git
    cd Pomodoro-Timer
    # open index.html in your browser
